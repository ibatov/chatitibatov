# Мессенджер

Простой чат на чистом HTML/CSS/JS, без сборки.

## Файлы
- `index.html` — разметка
- `style.css` — стили
- `script.js` — логика (чаты, сообщения, поиск людей, настройки, профиль, поддержка)

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Branch: main, папка `/`).

## Важно
Общая база и профили здесь работают через платформу claude.ai (`claude.use('db')`, `claude.use('user')`).
Вне claude.ai этих объектов нет, поэтому чат запускается в **локальном режиме**: сообщения видны только в вашем браузере и пропадают при перезагрузке.
Чтобы чат был общим на GitHub Pages, замените вызовы в `script.js` (`db.collection(...)`, `user.id()`, `user.search()`) на свою базу, например Firebase или Supabase.
